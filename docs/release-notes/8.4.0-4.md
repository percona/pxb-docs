# Percona XtraBackup 8.4.0-4 (2025-08-21)

Get started with [Quickstart Guide for Percona XtraBackup].

## Release highlights

This release provides improvements and bug fixes.

We recommend that you download the Percona XtraBackup for the same platform as the MySQL-compatible server. For example, if your server is on an ARM64 platform, you should download and use the Percona XtraBackup for ARM64 for that operating system.

## Bug fixes

[PXB-3571](https://perconadev.atlassian.net/browse/PXB-3571): If you use transition keys with `--lock-ddl=reduced`, XtraBackup does not save the encrypted tablespace keys in the `xtrabackup_keys` file. Consequently, XtraBackup prepare fails when it later attempts to open the encrypted tablespace.

[PXB-3470](https://perconadev.atlassian.net/browse/PXB-3470): When streaming a backup that has been compressed (using `lz4` or `zstd` with the `--compress` option), the decompression process, whether performed by `xbstream --decompress` or `xtrabackup --decompress`, requires a significant amount of time.

## Platform support

* Percona XtraBackup 8.4.0-4 supports Red Hat Enterprise Linux 10.

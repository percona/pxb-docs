# Install overview

We recommend that you install Percona XtraBackup 9.7 from the official Percona software repositories using the appropriate package manager for your system:

- [Use an APT repo to install Percona XtraBackup](https://docs.percona.com/percona-xtrabackup/9.7/apt-repo.html)
- [Use a YUM repo to install Percona XtraBackup](https://docs.percona.com/percona-xtrabackup/9.7/yum-repo.html)

## Installation alternatives

Percona also provides the following methods:

- [Use DEB downloaded packages to install Percona XtraBackup](https://docs.percona.com/percona-xtrabackup/9.7/apt-download-deb.html)
- [Use RPM downloaded packages to install Percona XtraBackup](https://docs.percona.com/percona-xtrabackup/9.7/yum-download-rpm.html)
- [Install Percona XtraBackup from a Binary Tarball](https://docs.percona.com/percona-xtrabackup/9.7/binary-tarball.html) with all the required files and binaries for a manual installation
- [Compile and install Percona XtraBackup from source code](https://docs.percona.com/percona-xtrabackup/9.7/compile-xtrabackup.html)
- [Run Percona XtraBackup in a Docker container](https://docs.percona.com/percona-xtrabackup/9.7/docker.html)

Before installing Percona XtraBackup with any of these methods, we recommend that you review the [release notes](https://docs.percona.com/percona-xtrabackup/9.7/release-notes/release-notes.html) and [Server version and backup version comparison](https://docs.percona.com/percona-xtrabackup/9.7/server-backup-version-comparison.html).
